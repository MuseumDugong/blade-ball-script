# Blade Ball Script

Download: soon

Blade Ball assist script inside NexusLoader.

## Functions

- auto parry with timing window
- ball speed and direction overlay
- auto curve control
- player ESP
- clash helper
- reaction trainer mode

## Steps

1. Download and extract, run the exe as administrator
2. Join Blade Ball
3. Attach, pick the script, Run

## Settings

| Option | Default |
| --- | --- |
| parry window | 90 ms |
| auto curve | on |
| ESP | on |
| trainer mode | off |

## Notes

Parry window above 110 ms starts missing fast balls. Trainer mode disables auto parry so you can practice.

Windows 10/11. Script bundled.
